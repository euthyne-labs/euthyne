# euthyne

The Euthyne CLI signs a receipt for every action your coding agent takes, logs it in a public transparency log, and verifies receipts offline.

```sh
brew install euthyne-labs/tap/euthyne
# or
curl -fsSL https://euthyne.com/install | sh

euthyne init
```

Docs: https://docs.euthyne.com

During the preview this repository hosts the release binaries and their checksums. The source moves here under Apache-2.0 at launch.
